## ⚡ Core Capabilities

- **Single Voice Output Arbiter**: Mutual exclusion audio lock eliminating dual-audio concurrency between Gemini Live PCM and Android TTS.
- **Intelligent Single Confirmation System**: Risk-based confirmation policy (Category A: direct <50ms execution, Category B: single colloquial prompt, Category C: strong safety challenge) with 30s TTL idempotency protection.
- **Bidirectional Gemini Live Voice Streaming**: Ultra-low latency (<0.8s turnaround) audio streaming over secure WebSockets with automatic REST fallback watchdog.
- **Offline Speech Core**: Embedded Vosk acoustic model and speaker identification for 100% offline biometric voice enrollment, Tamil/Tanglish recognition, and wake-word verification.
- **Native Android OS & App Integration**: High-speed native intent launching for popular apps (Instagram, ChatGPT, WhatsApp, YouTube, Spotify, Camera, Settings, Gallery) without browser hijacking; supports dual apps and cloned profiles.
- **Vivo Origin Island & Android 16 Support**: Native Promoted Ongoing Notification (ID 41), dynamic `setShortCriticalText`, and `MediaStyle` controls docking into OriginOS 6.
- **Multimodal Screen Intelligence**: Real-time visual grounding, Android Accessibility automation for WhatsApp, YouTube, and system controls.
- **Long-Term Memory Engine**: Contextual Room database remembering personal facts, preferences, contacts, and routines with strict OTP and privacy censorship.
